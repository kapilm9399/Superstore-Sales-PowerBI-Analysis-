# Superstore Sales & Profit Analysis Dashboard 📊

## Project Overview
This project analyzes over 10,000 retail sales records across 4 regions and 3 customer segments to evaluate sales performance and profitability. The data was cleaned in Excel and visualized using Power BI to uncover actionable business insights.

## Dashboard Preview
![Dashboard Preview](image.png)

## Tech Stack
* **Data Cleaning & Transformation:** Microsoft Excel
* **Data Visualization & Modeling:** Power BI (DAX, Interactive Visuals)
* **Data Source:** Kaggle

## Key Insights & Metrics
* Developed an interactive Power BI dashboard with 7+ visuals, tracking **$8.95M Sales**, **130K Quantity**, **$1.31M Profit**, and **$120.61K Shipping Cost**.
* Analyzed 12-month profit trends and identified the **Technology** category as the primary profit driver (~52% of total category profit).
* Revealed that the **Central region** is the most profitable operating area, contributing ~39.6% of overall regional profit.
